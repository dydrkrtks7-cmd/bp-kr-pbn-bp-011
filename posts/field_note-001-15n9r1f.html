### 구체적 니치 콘텐츠 작성

#### 맥락
클라우드/인프라 엣지케이스 / S3 버저닝 비용 폭증

#### 검색 의도 대응
- **AMI 조합**: 예측 가능한 CPU 크레딧 소진 시점을 구축하는 단계와 그 중요성.
- **오류코드**: 401 Unauthorized과 관련된 오류 처리 방법 및 이에 따른 비용 증가.

#### 구체성 원칙
- 버저닝 비용이 발생한 것은 "AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉"으로 인해 S3 버저닝 비용이 폭증했다.
- 이 문제는 특정 AMI 조합을 사용했을 때만 발생하였으며, 해당 AMI는 최신 엣지버전에서 생성되었다.

#### 사례
AMI 조합: `ami-0123456789abcdef` - S3 버저닝 비용 폭증이 발생한 시점

#### 사실성 원칙
AMI의 버저닝 비용 증가는 주로 오류코드 `401 Unauthorized`와 관련되었다. 이는 AWS API 요청 시 인증 정보가 부족하거나 올바르지 않아 발생하는 문제다.

#### 금지 지식 절대 규칙
- ❌ AWS 서비스 개요 (EC2/S3 설명)
- ❌ 클라우드 비용 절감 일반 팁
- ❔ 서버리스 아키텍처 장단점

#### 관점 강제: 재무 담당자 시점에서의 이야기
재무 담당자는 예상 밖으로 인한 가격 인하 공지를 놓친 순간이었다. 이로 인해 S3 버저닝 비용이 폭증했고, 이를 바로 인식하지 못했다. 결국 해당 AMI를 사용하면서 발생하는 비용 증가에 대해 혼란을 겪게 되었다.
